A complete story in exactly six words: forty years of marriage, then the first night apart.

## The story

> Forty years married. First night apart.

`main.ts` writes that line to `entry.txt` (to `MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`, else `./entry.txt`). Four candidate stories were compared against the judge brief in [CANDIDATES.md](CANDIDATES.md); this one won because the first sentence holds a whole life and the second is the turn, with the cause left unsaid.

## Run

```sh
node main.ts
```

Node 22+, standard library only, no network, deterministic.
